# カメレオンかくれんぼ

まっ白な人型キャラの体に絵を描いて、背景に擬態するかくれんぼゲーム。
Steam『めっちゃカメレオン』(LEMORION) に着想を得た**非公式のファン再現**です。
公式とは無関係で、モデル・テクスチャ・コードはすべてこのプロジェクト独自のものです。

---

## ファイル構成

```
めっちゃカメレオン/
├── index.html            ← ゲーム本体（HTML・CSS・JS 全部入り）
├── vendor/three.min.js   ← 3D ライブラリ（three.js r147）
├── server.mjs            ← 動作確認用のローカルサーバー（Node だけで動く）
└── README.md
```

## 1. とりあえず遊ぶ（パソコン）

`index.html` をダブルクリックするだけ。ブラウザで開いて「ひとりで練習」を押せば動きます。

うまく開けないときは、ターミナルでこのフォルダに入って:

```
node server.mjs
```

→ ブラウザで `http://localhost:5178` を開く。

## 2. 操作（原作のキー配置に合わせています）

**かくれる側は三人称、鬼は一人称**です（ペイント中はどちらも三人称になります）。
マウス固定（ポインタロック）は使いません。**画面をドラッグして視点**を動かします。
カメラは机やいすの背もたれより高い位置にあるので、教室でも見わたせます。

鬼の照準は**キャラの目の高さから、自分が向いている向き**に飛びます。
十字はその着弾点に出るので、画面の中央ではなく狙った先に表示されます。

### パソコン

| キー | できること |
|---|---|
| `W` `A` `S` `D` | 移動 |
| 画面をドラッグ | 視点（`D`＝右、`A`＝左） |
| `Space` | 上がる・浮く（押しっぱなしで上昇） |
| `Ctrl` | 下がる |
| `Shift` | 走る／壁への張り付きを解除する |
| `F` | ペイントモードを開く／閉じる |
| `R` | ポーズ変更（立つ → しゃがむ → 丸まる → のびる → 寝そべる） |
| `1` / `E` | 挑発（エモート） |
| クリック | （鬼のとき）みつけた！ |

### スマホ

- 左下のスティックで移動、画面をなぞって視点。
- 右下の ▲うく／▼さがる／≫走る（≫はタップで切りかえ）。
- 右側のボタンで ぬる／スポイト／ポーズ／エモート。
- 鬼のときは下の「みつけた!」ボタン。

## 3. ペイント（原作と同じ、体に直接描く方式）

`F`（またはスマホの🎨）でペイントモードに入ります。
**カメラの向きは入る前のまま**なので、視点が飛びません。
**ペイント中は自分は動きません**（カメラだけが動きます）。
**右側に色パネル**が出て、そこで色・太さ・ズーム・ポーズを変えます。

| したいこと | やりかた |
|---|---|
| **描く** | 自分の**体をドラッグ**する。体をなぞっている間は視点が動きません |
| **色をとる（スポイト）** | **背景をクリック／タップ**するだけ。`Space` でも十字の先の色をとれます |
| **太さを変える** | 右パネルの「太さ」スライダー（PCは背景を右ドラッグでも可） |
| **一色でぬりつぶす** | 「🪣 全身をこの色で塗る」 |
| **裏側を描く** | 背景をドラッグして自分のうしろ側に回りこむ |
| **視点を回す** | 体以外の場所をドラッグ（自分のまわりを自由に回れます） |
| **寄る／引く（フリーカメラ）** | ホイール／2本指ピンチ／パネルの `−` `＋`。顔や足先まで寄って描けます |
| **カメラを上下に振る** | 右ドラッグ（パネルの `⟳` で正面にリセット） |
| **カメラを動かす（フリーカメラ）** | `WASD`／スティックでカメラが平行移動。スマホは ▲▼ で上下。自分はその場に立ったままです |

> ペイント中のカメラは家具をすり抜けます（勝手に寄ると描きづらいため）。
> 真上・真下ちかくまで回せるので、**寝そべっているときも上から見おろして塗れます**。

体の表と裏はテクスチャが分かれているので、正面に描いた絵が背中に出ることはありません。

### 擬態のやりかた（いちばん簡単な勝ち筋）

1. 隠れたい壁や家具、**国旗**の前に立つ（国旗は厚い板になっていて、半分めり込めます）
2. `F` でペイントモードを開く
3. 背景をクリック／タップしてスポイト
4. 「🪣 全身をこの色で塗る」→ 一色で溶けこむ
5. あとはブラシで模様を描き足したり、`R` でポーズを変えてシルエットを崩す
6. 位置を直したいときは `F` でいったん閉じてから歩きます
7. `Space` で浮いて、壁ぎわで手をはなすとその高さで**張り付いたまま止まれます**（`Shift` で解除）

## 3.2 鬼の待機部屋

じゅんび時間のあいだ、鬼は「**まちあい室**」に入ります。校舎からは遠く離れているので、
隠れている人をのぞき見ることはできません。

この部屋でも `F` を押せば **鬼も自分に絵をかけます**。
壁にスポイト用の色みほん（16色）が貼ってあります。
描いた絵は**そのまま試合に持ちこまれます**（さがす時間に入っても消えません）。

さがす時間になると自動で校舎に出て、ペイントは閉じます。

## 3.5 練習モードで鬼も試せる

「ひとりで練習」中は、右のボタン **👹 鬼になる** で役を切りかえられます。
鬼になると体が 120% になり、銃を構え、クリック（スマホは「みつけた!」）で発砲できます。
もういちど押すと **🎨 かくれる** 側に戻ります。

## 4. 体の大きさ・鬼のちがい

| | かくれる側 | 鬼 |
|---|---|---|
| 体の大きさ | 80% | 120% |
| 移動 | ふつう | 1.1倍 |
| ペイント | いつでも | じゅんび時間（待機部屋）だけ |
| ポーズ | できる | **できる**（しゃがんで物陰から覗ける） |
| 見た目 | 手ぶら | **銃を構えている**（一人称でも手元に出ます） |

## 4.5 音とレーダー

音は Web Audio でその場で合成しています（音声ファイルは無し）。
ブラウザの制限で、**タイトル画面のボタンを押した時点**で音が有効になります。

### 銃

- 鬼が撃つと **「バン！」** と鳴り、**弾すじ（トレーサー）** が銃口から着弾点まで飛びます。
- 当たっても外しても鳴ります。壁・椅子・机に当たれば、そこで弾すじが止まります。
- 音は**距離で小さく、左右に振りわけ**られるので、遠くの発砲もどちらから来たか分かります。

### 口笛と方向レーダー

- かくれる側は **10秒に1回、自動で口笛** を鳴らします（自分では止められません）。
- 誰かの口笛が聞こえると、**右上の4分割マス**の、聞こえた方向のマスが光ります。
- **上＝自分が向いている方向**です。振り向くと印もちゃんと追従します（向きはワールド座標で覚えているため）。
- 正確な角度を示す白い点も出ます。
- 印が出るのは **1秒だけ**です。

> 「ひとりで練習」では、レーダーの見かたを覚えられるように、10秒ごとに適当な場所から口笛が鳴ります。

### 壁へのめり込みルール

壁や家具には**半分くらいまで**めり込めます。ただし、

- **体が 30% 以上出ていないとダメ**です。
- 出ていない状態が続くと画面下に警告が出て、**10秒後に自分の位置が鬼に知らされます**（鬼の画面に赤い目印が出ます）。
- 壁を通り抜けることはできません。`Shift` で張り付きを解除して離れられます。

## 5. オンライン対戦を有効にする（無料・1回だけの設定）

通信は **Supabase Realtime** を使います。データベースもサーバーコードも不要で、
無料プランのままで動きます。**テーブルを作る必要もありません。**

### 手順

1. <https://supabase.com> でアカウントを作り、**New project** で新しいプロジェクトを1つ作る
   （リージョンは `Northeast Asia (Tokyo)` が速いです。パスワードは使わないので何でも可）
2. プロジェクトができたら左メニューの **Settings → API** を開く
3. 次の2つをコピーする
   - **Project URL**（`https://xxxxxxxx.supabase.co`）
   - **Project API keys** の **`anon` `public`** のほう
     ※ `service_role` のキーは**絶対に使わないでください**（誰でも全データを触れてしまいます）
4. ゲームのタイトル画面 →「⚙ オンライン設定」に貼りつけて、名前を入れて **保存**

これで「部屋をつくる」が使えます。表示された4文字のコードを友だちに伝えて、
相手は「部屋コード」に入れて「入る」を押すだけ。

> 遊ぶ人**全員**が同じ URL と anon key を設定する必要があります。
> （URL とキーを friends に伝えるか、下の手順でホスティングしてしまうのが楽です）

### ゲームの流れ

- ロビーで、いちばん最初に入った人が**ホスト**（鬼の人数・時間を決めて開始）
- **じゅんび時間**: 隠れる人は塗って隠れる。鬼は**待機部屋**へ送られます（校舎は見えません）
- **さがす時間**: 鬼が探して、狙って「みつけた!」。全員みつかれば鬼チームの勝ち
- 時間切れで1人でも生き残っていれば、かくれチームの勝ち

## 6. スマホから遊べるようにする（ネットに置く）

スマホのブラウザから開くには、どこかに置いて HTTPS の URL にする必要があります。
いちばん手間がないのは **Netlify Drop**（無料・アカウントなしでも可）:

1. <https://app.netlify.com/drop> を開く
2. この「めっちゃカメレオン」フォルダを**まるごとドラッグ&ドロップ**
3. 出てきた URL をスマホで開く

GitHub Pages や Vercel、Cloudflare Pages でも同じように置けます
（静的ファイルだけなので、ビルド設定は不要です）。

## 7. 調整したいとき（index.html の中）

| やりたいこと | 場所 |
|---|---|
| マップの部屋わけ・家具 | `buildWorld()`（`chair` `table` `shelf` `sofa` `bench` `plant` `tree` などのヘルパあり） |
| 床の色・模様 | `buildWorld()` 内の `floorTex` |
| 国旗 | `flagTexture()` / `flagBanner()` / `flagPole()` |
| キャラの体型 | `PARTS`（頭は球、胴と手足はカプセル） |
| 体の大きさ | `HIDER_SCALE`(0.8) / `SEEKER_SCALE`(1.2) |
| 鬼の銃 | `makeGun()` |
| ポーズと移動速度 | `POSES` |
| めり込みの深さ・通報までの秒数 | `EMBED_DEPTH` / `EMBED_MIN`（0.30＝30%）/ `REVEAL_SEC`（10秒） |
| 浮ける高さ・重力 | `CEIL_Y` / `GRAVITY` |
| 見つける距離 | `ray.far`（初期値 26m） |
| 口笛の間隔・印の表示時間 | `WHISTLE_EVERY`（10秒）/ `WHISTLE_SHOW`（1000ms） |
| 銃声・口笛の音 | `playBang()` / `playWhistle()` |
| 弾すじ | `spawnTracer()` |
| ペイントの解像度 | `SKIN_W` / `SKIN_H`（512×512。左半分＝正面／右半分＝背面） |

マップは固定の乱数シード（`makeRng(20260610)`）から作っているので、
全員がまったく同じ地形になります。シードを変えると別マップになります。

### マップの構成（学校）

```
              北
  ┌────────┬────────┬────────┬──────┐
  │ 1年1組  │ 1年2組  │ 理科室  │ 音楽室│  黒板・時間割・時計
  │ 机といす │ 机といす │ 実験台  │ ひな壇│  うしろは番号つきロッカー
  ├──────── 北廊下（窓・掲示板・時計）────────┤
  │                                        │
  │            中庭（芝・砂・木・花壇）      │  日仏の国旗ポール
  │            ベンチ・鉄棒                  │
  ├──────── 南廊下 ───────────────────────┤
  │   体育館        │  図書室   │  昇降口   │
  │ コート・ゴール   │  本棚     │  下駄箱   │
  │ 跳び箱・マット   │  机といす │ (番号つき) │
  │ ステージ＋国旗   │           │           │
  └────────┴────────┴────────┴──────┘
              南
```

**学校らしい数字**：黒板の日付と計算式（`7 × 8 = 56` など）、教室札（`1-1` `1-2`）、
時間割の表、ロッカーと下駄箱の番号、時計の文字盤。

**隠れ場所**：机の下・いすの列にまぎれる／ロッカー・下駄箱・本棚・壁にめり込む／
跳び箱・マット／体育館ステージの国旗／中庭の木と花壇。

いすは**座面に乗れます**。いす → 机 → ロッカーの上、と段差をつたって高い所へも行けます
（`Space` で浮けば、どこへでも）。
