# カメレオンかくれんぼ

まっ白な人型キャラの体に絵を描いて、背景に擬態するかくれんぼゲーム。
Steam『めっちゃカメレオン』(LEMORION) に着想を得た**非公式のファン再現**です。
公式とは無関係で、モデル・テクスチャ・コードはすべてこのプロジェクト独自のものです。

---

## ファイル構成

```
めっちゃカメレオン/
├── index.html            ← ゲーム本体（HTML・CSS・JS 全部入り）
├── vendor/three.min.js   ← 3D ライブラリ（three.js r147）
├── server.mjs            ← 動作確認用のローカルサーバー（Node だけで動く）
└── README.md
```

## 1. とりあえず遊ぶ（パソコン）

`index.html` をダブルクリックするだけ。ブラウザで開いて「ひとりで練習」を押せば動きます。

うまく開けないときは、ターミナルでこのフォルダに入って:

```
node server.mjs
```

→ ブラウザで `http://localhost:5178` を開く。

## 2. 操作（原作のキー配置に合わせています）

**かくれる側は三人称、鬼は一人称**です（ペイント中はどちらも三人称になります）。
マウス固定（ポインタロック）は使いません。**画面をドラッグして視点**を動かします。
カメラは机やいすの背もたれより高い位置にあるので、教室でも見わたせます。

鬼の照準は**キャラの目の高さから、自分が向いている向き**に飛びます。
十字はその着弾点に出るので、画面の中央ではなく狙った先に表示されます。

### パソコン

| キー | できること |
|---|---|
| `W` `A` `S` `D` | 移動 |
| 画面をドラッグ | 視点（`D`＝右、`A`＝左） |
| `Space` | 上がる・浮く（押しっぱなしで上昇） |
| `Ctrl` | 下がる |
| `Shift` | 走る／壁への張り付きを解除する |
| `F` | ペイントモードを開く／閉じる |
| `R` | ポーズの一覧を出す（`1`〜`5` で直接えらべます） |
| `C` | ぶんしん（クローン）を置く |
| `5` | フリーカメラ（自分はその場に残る） |
| クリック | （鬼のとき）みつけた！ |

### スマホ

- **画面の左半分のどこを押しても、そこにスティックが出ます**（左下の丸は目印です）。
  そのまま指をずらして移動。右半分をなぞると視点。
- 右下の ▲うく／▼さがる／≫走る（≫はタップで切りかえ）。
- 右側のボタンで ぬる／スポイト／ポーズ／フリーカメラ／ぶんしん。
- **ポーズ**は押すと一覧が出るので、なりたい形をえらびます。
- 鬼のときは下の「みつけた!」ボタン。

## 3. ペイント（原作と同じ、体に直接描く方式）

`F`（またはスマホの🎨）でペイントモードに入ります。
**カメラの向きは入る前のまま**なので、視点が飛びません。
**ペイント中は自分は動きません**（カメラだけが動きます）。
**右側に色パネル**が出て、そこで色・太さ・ズーム・ポーズを変えます。

| したいこと | やりかた |
|---|---|
| **描く** | 自分の**体をドラッグ**する。体をなぞっている間は視点が動きません |
| **色をとる（スポイト）** | **背景をクリック／タップ**するだけ。`Space` でも十字の先の色をとれます |
| **太さを変える** | 右パネルの「太さ」スライダー（PCは背景を右ドラッグでも可） |
| **一色でぬりつぶす** | 「🪣 全身をこの色で塗る」 |
| **裏側を描く** | 背景をドラッグして自分のうしろ側に回りこむ |
| **視点を回す** | 体以外の場所をドラッグ（自分のまわりを自由に回れます） |
| **寄る／引く（フリーカメラ）** | ホイール／2本指ピンチ／パネルの `−` `＋`。顔や足先まで寄って描けます |
| **カメラを上下に振る** | 右ドラッグ（パネルの `⟳` で正面にリセット） |
| **カメラを動かす（フリーカメラ）** | `WASD`／スティックでカメラが平行移動。スマホは ▲▼ で上下。自分はその場に立ったままです |

> ペイント中のカメラは家具をすり抜けます（勝手に寄ると描きづらいため）。
> 真上・真下ちかくまで回せるので、**寝そべっているときも上から見おろして塗れます**。

体の表と裏はテクスチャが分かれているので、正面に描いた絵が背中に出ることはありません。

### 擬態のやりかた（いちばん簡単な勝ち筋）

1. 隠れたい壁や家具、**国旗**の前に立つ（国旗は厚い板になっていて、半分めり込めます）
2. `F` でペイントモードを開く
3. 背景をクリック／タップしてスポイト
4. 「🪣 全身をこの色で塗る」→ 一色で溶けこむ
5. あとはブラシで模様を描き足したり、`R` でポーズを変えてシルエットを崩す
6. 位置を直したいときは `F` でいったん閉じてから歩きます
7. `Space` で浮いて、壁ぎわで手をはなすとその高さで**張り付いたまま止まれます**（`Shift` で解除）

## 3.2 鬼の待機部屋

じゅんび時間のあいだ、鬼は「**まちあい室**」に入ります。校舎からは遠く離れているので、
隠れている人をのぞき見ることはできません。

この部屋でも `F` を押せば **鬼も自分に絵をかけます**。
壁にスポイト用の色みほん（16色）が貼ってあります。
描いた絵は**そのまま試合に持ちこまれます**（さがす時間に入っても消えません）。

さがす時間になると自動で校舎に出て、ペイントは閉じます。

## 3.5 練習モードで鬼も試せる

「ひとりで練習」中は、右のボタン **👹 鬼になる** で役を切りかえられます。
鬼になると体が 120% になり、銃を構え、クリック（スマホは「みつけた!」）で発砲できます。
もういちど押すと **🎨 かくれる** 側に戻ります。

## 4. 体の大きさ・鬼のちがい

| | かくれる側 | 鬼 |
|---|---|---|
| 体の大きさ | 80% | 120% |
| 移動 | ふつう | 1.1倍 |
| ペイント | いつでも | じゅんび時間（待機部屋）だけ |
| つかまると | **鬼になる**（脱落しない） | — |
| ポーズ | できる | **できる**（しゃがんで物陰から覗ける） |
| 見た目 | 手ぶら | **銃を構えている**（一人称でも手元に出ます） |

## 4.5 音とレーダー

音は Web Audio でその場で合成しています（音声ファイルは無し）。
ブラウザの制限で、**タイトル画面のボタンを押した時点**で音が有効になります。

### 銃

- 鬼が撃つと **「バン！」** と鳴り、**弾すじ（トレーサー）** が銃口から着弾点まで飛びます。
- 当たっても外しても鳴ります。壁・椅子・机に当たれば、そこで弾すじが止まります。
- 音は**距離で小さく、左右に振りわけ**られるので、遠くの発砲もどちらから来たか分かります。

### 🎥 フリーカメラ

`5` キー（スマホは 🎥 ボタン）で、**自分をその場に残したままカメラだけ飛ばせます**。

- 隠れたあと、鬼から自分がどう見えているかを確認するのに使います。
- `WASD`／スティックで移動、`Space`/`Ctrl`（スマホは ▲▼）で上下、`Shift` で速く。
- **マップの中ならどこまでも**飛べます。
- もう一度押すと戻ります。ペイントを開くと自動で解除されます。

### ぶんしん（クローン）

かくれる側は `C`（スマホは 👥 ぶんしん）で、**自分のコピーをその場に置けます**。

- **1人3体まで**。いまの塗り・**ポーズ**・向きがそのままコピーされます（寝そべりも丸まりもそのまま）。
- **撃たれても本人は無事**です。鬼には「ぶんしんだった！」と出ます。
- 撃たれたぶんしんは消えるので、置きなおしできます。

### 口笛と方向レーダー

- かくれる側は **10秒に1回、自動で口笛** を鳴らします（自分では止められません）。
- 誰かの口笛が聞こえると、**右上の4分割マス**の、聞こえた方向のマスが光ります。
- **上＝自分が向いている方向**です。振り向くと印もちゃんと追従します（向きはワールド座標で覚えているため）。
- 正確な角度を示す白い点も出ます。
- 印が出るのは **1秒だけ**です。
- **誰かが発砲すると、全員のレーダーに黄色い印**が出ます（口笛は赤）。近くなら「🔫 発砲音！」も出ます。

> 「ひとりで練習」では、レーダーの見かたを覚えられるように、10秒ごとに適当な場所から口笛が鳴ります。

### 壁へのめり込みルール

壁や家具には**半分くらいまで**めり込めます。ただし、

- **体が 10% 以上出ていないとダメ**です。
- 出ていない状態が続くと画面下に警告が出て、**10秒後に自分の位置が鬼に知らされます**（鬼の画面に赤い目印が出ます）。
- 壁を通り抜けることはできません。`Shift` で張り付きを解除して離れられます。

## 5. オンライン対戦を有効にする（無料・1回だけの設定）

通信は **Supabase Realtime** を使います。データベースもサーバーコードも不要で、
無料プランのままで動きます。**テーブルを作る必要もありません。**

### 手順

1. <https://supabase.com> でアカウントを作り、**New project** で新しいプロジェクトを1つ作る
   （リージョンは `Northeast Asia (Tokyo)` が速いです。パスワードは使わないので何でも可）
2. 上部の **Connect** ボタンを押す（URL とキーがまとめて出ます）
   - メニューからたどる場合は **Settings（歯車）→ API Keys**
3. 次の2つをコピーする
   - **Project URL**（`https://xxxxxxxx.supabase.co`）
   - **キー**。API Keys にはタブが2つあり、**どちらでも動きます**
     - `Publishable and secret API keys` タブ → **Publishable key**（`sb_publishable_...`）
       ※無ければ `Create new API Keys` で作れます
     - `Legacy API keys` タブ → **anon public**（`eyJhbGci...`）
     - ⚠️ `secret` / `service_role` のキーは**絶対に使わないでください**（全データを触れてしまいます）
4. `index.html` を開いて、いちばん上のほうにある次の場所に貼りつける

```js
/* ★ ここに Supabase の情報を貼ってください ★ */
const DEFAULT_CFG = {
  url: '',      ← ここに Project URL
  key: ''       ← ここに Publishable / anon public キー
};
```

`index.html` はテキストエディタ（メモ帳／VS Code／Xcode なんでも可）で開けます。
`''` のあいだに貼るだけです。例:

```js
const DEFAULT_CFG = {
  url: 'https://abcdefgh.supabase.co',
  key: 'sb_publishable_xxxxxxxxxxxxxxxx'
};
```

これで **遊ぶ友だちは何も設定しなくてOK** になります（名前だけ入力）。
貼らずに、各自がタイトル画面の「⚙ オンライン設定」に入力する方式でも動きます。

これで「部屋をつくる」が使えます。表示された4文字のコードを友だちに伝えて、
相手は「部屋コード」に入れて「入る」を押すだけ。

> ⚠️ **公開リポジトリに置く場合**、貼った anon key は誰でも見られます。
> anon key はもともとブラウザに配る前提の鍵なので致命的ではありませんが、
> 無関係な人に通信枠を使われる可能性はあります。気になったら Supabase 側で
> キーを作り直せば、古いキーは無効になります。

### ゲームの流れ

- ロビーで、いちばん最初に入った人が**ホスト**（鬼の人数・時間を決めて開始）
- **じゅんび時間**: 隠れる人は塗って隠れる。鬼は**待機部屋**へ送られます（校舎は見えません）
- **さがす時間**: 鬼が探して、狙って「みつけた!」
- **撃たれた人はその場で鬼になります**。鬼はどんどん増えていきます
- 全員が鬼になれば鬼チームの勝ち。時間切れで1人でも逃げきればかくれチームの勝ち
- **答え合わせ（20秒）**: 勝負がついたあと、全員の居場所が**壁ごしに点滅して**見えます。
  つかまった人は**つかまった場所**に立って表示されます。
  この間はみんな自由に動けます（撃てません）。そのあと結果画面へ

## 6. GitHub に置いて、スマホから遊べるようにする

スマホのブラウザから開くには、HTTPS の URL が必要です。
**GitHub Pages** なら無料で、リポジトリを置くだけで公開できます。

### 6-1. GitHub Desktop でアップロードする

1. <https://desktop.github.com> から **GitHub Desktop** をダウンロードして入れる
2. 起動して GitHub アカウントでログイン（アカウントが無ければその場で作れます）
3. メニューの **File → Add Local Repository…**
4. このフォルダ（`めっちゃカメレオン`）を選ぶ
   - すでに Git の準備はできているので、そのまま追加できます
5. 右上の **Publish repository** を押す
6. ここで **Name を半角英数にする**（例: `chameleon-kakurenbo`）
   - フォルダ名が日本語なので、そのままだと URL が読みにくくなります
7. **Keep this code private のチェックを外す**（Pages を無料で使うため）
8. **Publish repository** を押す

以降、ファイルを直したら GitHub Desktop の左下で
コメントを書いて **Commit** → 右上 **Push origin** で反映されます。

### 6-2. GitHub Pages を有効にする

1. ブラウザで自分のリポジトリを開く
2. **Settings** タブ → 左メニューの **Pages**
3. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**
4. 1〜2分待つと、ページ上部に URL が出ます

```
https://（あなたのユーザー名）.github.io/chameleon-kakurenbo/
```

この URL をスマホで開けば遊べます。友だちにもこの URL を渡すだけです。

> Pages に反映されるまで少し時間がかかります。すぐ変わらなくても数分待ってください。

### 6-3. Netlify Drop でもOK（GitHub を使いたくないとき）

1. <https://app.netlify.com/drop> を開く
2. このフォルダを**まるごとドラッグ&ドロップ**
3. 出てきた URL をスマホで開く

## 7. 調整したいとき（index.html の中）

| やりたいこと | 場所 |
|---|---|
| マップの追加・切りかえ | `MAPS` 配列と `buildMap()` |
| 各マップの中身 | `buildSchool()` / `buildBackrooms()` / `buildOsaka()` |
| 家具や壁を置くヘルパ | `box` `cyl` `sph` `flat` `wall` `floorAt` `desk` `schoolChair` `bookshelf` など（module 直下） |
| 国旗 | `flagTexture()` / `flagBanner()` / `flagPole()` |
| キャラの体型 | `PARTS`（頭は球、胴と手足はカプセル） |
| 体の大きさ | `HIDER_SCALE`(0.8) / `SEEKER_SCALE`(1.2) |
| 鬼の銃 | `makeGun()` |
| ポーズと移動速度 | `POSES` |
| めり込みの深さ・通報までの秒数 | `EMBED_DEPTH` / `EMBED_MIN`（0.10＝10%）/ `REVEAL_SEC`（10秒） |
| 浮ける高さ・重力 | `CEIL_Y` / `GRAVITY` |
| 見つける距離 | `ray.far`（初期値 26m） |
| 口笛の間隔・印の表示時間 | `WHISTLE_EVERY`（10秒）/ `WHISTLE_SHOW`（1000ms） |
| 銃声・口笛の音 | `playBang()` / `playWhistle()` |
| 弾すじ | `spawnTracer()` |
| ぶんしんの上限 | `MAX_CLONES`（3体） |
| ペイントの解像度 | `SKIN_W` / `SKIN_H`（512×512。左半分＝正面／右半分＝背面） |

マップは固定の乱数シード（`makeRng(20260610)`）から作っているので、
全員がまったく同じ地形になります。シードを変えると別マップになります。

### マップ

2つあります。タイトル画面（練習）とロビー（対戦）で選べます。対戦ではホストが選んだマップに全員が合わせられます。

#### 1. 学校

```
              北
  ┌────────┬────────┬────────┬──────┐
  │ 1年1組  │ 1年2組  │ 理科室  │ 音楽室│  黒板・時間割・時計
  ├──────── 北廊下（窓・掲示板）──────────┤
  │        中庭（芝・砂・木・花壇・鉄棒）      │  日仏の国旗ポール
  ├──────── 南廊下 ───────────────────────┤
  │   体育館      │  図書室   │  昇降口     │
  └────────┴────────┴────────┴──────┘
              南
```

黒板の計算式（`7 × 8 = 56`）、教室札（`1-1`）、時間割、ロッカーと下駄箱の番号など、
学校らしい数字を入れてあります。いすは座面に乗れて、いす→机→ロッカーと登れます。

**隠れ場所**：窓ぎわのカーテン（めり込める）／段ボールの山／給食の配膳台／
消火栓の赤い箱／傘立て／パイプいすの山／廊下の手洗い場／
体育館の舞台袖の幕・ボールかご・たたんだマット・平均台・得点板／
中庭のジャングルジム（中に入れる・上に乗れる）・砂場・物置・タイヤとび・自転車おきば／
図書室の返却ワゴン。

#### 2. 道頓堀

夜の川ぞい。真ん中を**道頓堀川**が流れていて、両岸にネオンのビルが並びます。

- **川に当たり判定はありません**。岸から歩いて落ちれば、そのまま**川底まで沈めます**。
  水面ごしに岸の様子も見えるので、潜って隠れるのがそのまま作戦になります。
  上がるときは `Space` で浮いてください。
- **観光船が2隻**浮かんでいます。甲板に乗れます。
- **えびす橋**（アーチの歩道橋）を渡れます。上は見晴らしがいいぶん目立ちます。
- **上へは 9m まで浮けます**（学校は 6m）。ビルの看板を見上げながら移動できます。
- **お店の中に入れます**。入口ののれんをくぐると、たこ焼きの鉄板・ラーメンのカウンターと丸いす・
  居酒屋のテーブル席など、店ごとに中身がちがいます。壁ぎわの棚にはびんが並んでいます。
- 名物の大看板は**立体**です。**かに**は脚とはさみが動き、**たこ**は足がゆれ、**ビールの缶**は
  泡があふれています。走る人だけは平面のネオンです。
- ほかに縦看板、店先のシャッター、街灯、手すり、屋台、自販機、自転車、ゴミ袋、
  立ち飲みテーブル、電話ボックス。
- 川の中にも沈んだ箱や杭があるので、水中でも輪郭を隠せます。

> 実在の場所の雰囲気を参考にしていますが、**お店の名前やロゴは実在のものを使わず、
> すべて独自にデザインしています**。
